  • training_simulator/ui/main_window.py

New Methods Added:

1. _show_patient_complete_message(frame, role, current_day)
   → Displays completion message when one patient finishes
   → Shows patient name and encourages switching
   → Visual: ✓ checkmark emoji in sky-blue

   → Scans all patients for next events
   → Returns sorted list: [(name, day, event_count), ...]
   → Looks ahead up to 30 days
   → Sorts by day, then by patient name

Enhanced Method:

1. _update_display()
   → Added completion detection logic
   → Checks if all patients done
   → Routes to appropriate message function
   → Maintains existing behavior for normal events

NEXT EVENTS PREVIEW LOGIC
================================================================================

Algorithm:
1. For each patient/role
2. Starting from (current_day + 1)
3. Look ahead up to 30 days
4. Find first day with events for that patient
5. Count events on that day
6. Collect: (patient_name, event_day, event_count)

Filtering:
7. Sort by event_day (ascending), then by patient_name (ascending)
8. Return top 3 results (prevents clutter)
9. Fallback: show "No upcoming events" if none found

Example:
  Scanning from Day 8 (because we're on Day 7):
  • Exp - Left:    first event on Day 7 ← already on current day, skip
  • Ctrl - Left:   first event on Day 7 ← already on current day, skip
  • Exp - Right:   first event on Day 8 ✓ include
  • Ctrl - Right:  first event on Day 10 ✓ include
  • Ctrl - Alt:    first event on Day 20 ✓ include

  Display (sorted):
  1. Exp - Right — Day 8 (3 events)
  2. Ctrl - Right — Day 10 (2 events)
  3. Ctrl - Alt — Day 20 (1 event)

CUSTOMIZATION GUIDE
================================================================================

To change message text:
  1. Open: training_simulator/ui/main_window.py
  2. Find: _show_patient_complete_message() and _show_day_complete_message()
  3. Edit: .configure(text="...") lines
  4. Save and restart simulator

To change colors:
  1. Open: training_simulator/ui/widgets.py
  2. Find: Color constants (ACCENT, FG_LIGHT, etc.)
  3. Edit: Hex color codes
  4. Save and restart (affects all messages)

To change lookahead distance:
  1. Open: training_simulator/ui/main_window.py
  2. Find: _get_next_events() method
  3. Edit: min(start_day + 30, ...) → change 30 to desired days
  4. Save and restart

To change preview limit:
  1. Open: training_simulator/ui/main_window.py
  2. Find: for patient_name, day, event_count in next_events[:3]
  3. Edit: [:3] → [:5] for 5 events, etc.
  4. Save and restart
