COLOR CODING IN MESSAGES

Patient Completion (✓):
  ✓ emoji in sky-blue (#0ea5e9)
  "All Events Completed!" in dark slate (#1e293b)
  Body text in slate (#334155)
  Guidance in bold sky-blue (#0ea5e9)

Day Completion (🎉):
  🎉 emoji in sky-blue (#0ea5e9)
  "Day X Complete!" in dark slate (#1e293b)
  Body text in slate (#334155)
  "📋 Next Events Preview" header in sky-blue (#0ea5e9)
  Event items in slate (#334155)
  Guidance in bold sky-blue (#0ea5e9)

All backgrounds: light (#f8fafc)
All dividers: light gray (#e2e8f0)

MESSAGE TIMING & TRIGGERS

Event                    Trigger                  Message Type
─────────────────────────────────────────────────────────────────────────
Patient completes        User clicks patient      ✓ Patient Complete
all events              tab with no events
                        (others still busy)

All patients            All patients have         🎉 Day Complete
complete day            no events                 + Next Events Preview

Day has no events       Initial load of day       🎉 Day Complete
from start              with no patient events   + Next Events Preview

User switches           User clicks sidebar      ✓ Patient Complete
to completed patient    when already done        (if still done)

EXAMPLE WORKFLOW: 2-PATIENT SIMULATION

Day 1 Start:
┌─ Tab A: Event 1, Event 2, Event 3 [3 events]
└─ Tab B: Event 1, Event 2 [2 events]

User completes Tab A:
┌─ Tab A: ✓ All Events Completed! Switch to another patient
└─ Tab B: Event 1, Event 2 [2 events]

User switches to Tab B:
┌─ Tab A: [hidden]
└─ Tab B: Event 1, Event 2 [2 events]

User completes Tab B:
┌─ Tab A: [hidden]
└─ Tab B: 🎉 Day 1 Complete! Next Events Preview: Patient A - Day 3, Patient B - Day 7
          👉 Click "Advance Day"

User clicks "Advance Day":
Day 2 Start:
┌─ Tab A: No events scheduled for Day 2
└─ Tab B: No events scheduled for Day 2

Display ALL TABS:
┌─ Tab A: 🎉 Day 2 Complete! Next Events Preview: Patient A - Day 3, Patient B - Day 7
└─ Tab B: 🎉 Day 2 Complete! Next Events Preview: Patient A - Day 3, Patient B - Day 7
         👉 Click "Advance Day"

User clicks "Advance Day":
Day 3 Start:
┌─ Tab A: Event 1 [1 event]
└─ Tab B: No events scheduled for Day 3
