WHAT WAS CHANGED
================================================================================

The Training Simulator's Tkinter GUI has been redesigned from a DARK THEME
to a PROFESSIONAL LIGHT THEME suitable for clinical training environments.

FILES MODIFIED:
  ✓ training_simulator/ui/widgets.py
  ✓ training_simulator/ui/setup_dialog.py
  ✓ training_simulator/ui/verification_dialog.py
  ✓ training_simulator/ui/main_window.py (documentation)

  ✓ training_simulator/ui/COLOR_PALETTE.md (color reference guide)

================================================================================
KEY COLOR CHANGES
================================================================================

BACKGROUNDS:
  Before: #1e293b (dark slate-800)
  After:  #f8fafc (light slate-50)

  Before: #0f172a (very dark slate-950)
  After:  #e8eef7 (light blue-gray)

TEXT COLORS:
  Before: #f1f5f9 (light text on dark)
  After:  #1e293b (dark text on light)

  Before: #94a3b8 (secondary on dark)
  After:  #64748b (secondary on light)

PRIMARY ACCENT:
  Before: #a855f7 (purple)
  After:  #0ea5e9 (sky-blue) — more professional

STATUS COLORS:
  All status backgrounds now use light pastels:
  • Pending:     light gray
  • In Progress: light amber
  • Complete:    light green
  • Needs Fixes: light red

================================================================================
DESIGN TOKENS (TECHNICAL)
================================================================================

Light Theme Color Palette:

Background & Surfaces:
  BG_DARK = '#f8fafc'        # Page background (light)
  BG_DARKER = '#e8eef7'      # Header/sidebar (light blue-gray)
  BG_CARD = '#ffffff'        # Content cards (white)
  BORDER = '#e2e8f0'         # Subtle dividers

Text Colors:
  FG_LIGHT = '#1e293b'       # Headings (dark slate)
  FG_BODY = '#334155'        # Body text (slate)
  FG_MUTED = '#64748b'       # Secondary text (muted)
  FG_DIM = '#475569'         # Tertiary text (dim)

Accent & Interactive:
  ACCENT = '#0ea5e9'         # Primary (sky-blue)
  ACCENT_HOVER = '#0284c7'   # Hover (darker sky-blue)
  VALUE_COLOR = '#0369a1'    # Data (teal-blue)

Status Colors (with Light Backgrounds):
  Pending:    '#94a3b8' on '#f1f5f9'
  In Progress: '#f59e0b' on '#fef3c7'
  Complete:   '#16a34a' on '#dcfce7'
  Needs Fixes: '#dc2626' on '#fee2e2'

   - Restore FG_LIGHT = '#f1f5f9'
   - Restore FG_BODY = '#e2e8f0'
   - Restore ACCENT = '#a855f7'
   - Restore status colors to original dark backgrounds

2. In setup_dialog.py and verification_dialog.py:
   - Restore color constants to original values
