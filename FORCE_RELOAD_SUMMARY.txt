================================================================================
WHAT IT DOES
================================================================================

When user clicks "Advance Day" button:

BEFORE (Simple Update):
  • Day advances
  • Display updates
  • Some UI state might persist

AFTER (Force Reload):
  • Day advances
  • Show: "🔄 Reloading dashboard..."
  • Clear ALL tabs completely
  • Rebuild tabs from scratch
  • Reset to first patient
  • Load fresh data from disk
  • Display: Day X events
  ✓ Guaranteed clean, fresh state

def _force_reload_dashboard(self):
    # 1. Show loading feedback
    self.status_bar.set_status('🔄 Reloading dashboard...', cohort_active=True)
    self.update()  # Process UI update

    try:
        # 2. Clear all tabs
        for tab in self.notebook.tabs():
            self.notebook.forget(tab)

        # 3. Rebuild tabs
        self.tabs = {}
        for role in self.roles:
            frame = tk.Frame(self.notebook, bg=BG_DARK)
            self.notebook.add(frame, text=self.role_names[role])
            self.tabs[role] = frame

        # 4. Reset to first patient
        if self.roles:
            self.notebook.select(0)
            self.selected_role.set(self.roles[0])
            self._highlight_selected_patient()

        # 5. Update display
        self._update_display()

        # 6. Restore normal status
        self.status_bar.set_status(...)
    except Exception as e:
        # 7. Error handling
        messagebox.showerror('Reload Error', f'Failed to reload dashboard:\n{e}')

================================================================================
HOW IT WORKS (STEP BY STEP)
================================================================================

User clicks "Advance Day" button:

Step 1: Validate State
  → Check if cohort exists
  → Check if day < 187

Step 2: Advance Day
  → Call day_engine.advance_day()
  → Increment cohort_day counter

Step 3: Update UI (Day Spinbox)
  → Update day spinbox to new day number

Step 4: Update UI (Status Bar)
  → Update status to show new day
  → Update progress bar

Step 5: Force Reload (NEW)
  → Show "🔄 Reloading..." status
  → Clear all notebook tabs
  → Rebuild all tabs
  → Reset selection to first patient
  → Call _update_display() for fresh data
  → Restore normal status

Step 6: Done
  → Dashboard refreshed
  → New day displayed
  → Ready for user input

Elapsed time: ~100-200ms (mostly imperceptible)
