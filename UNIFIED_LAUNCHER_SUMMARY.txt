================================================================================

    ↓
Unified Launcher Starts
    ├─ Thread 1 (Background): Flask Web Server
    │  └─ Starts on http://localhost:5000

Both run independently without blocking each other!

ARCHITECTURE
================================================================================

File: app_launcher.py

Function run_flask_server():
  • Starts Flask on background thread
  • Listens on localhost:5000
  • Runs without blocking main thread

Function run_training_simulator():
  • Starts Tkinter GUI on main thread
  • Tkinter requirement: must be main thread
  • Normal interactive behavior

Function main():
  • Creates background thread for Flask
  • Runs Simulator on main thread
  • Handles startup/shutdown

================================================================================
AUTO-REFRESH
================================================================================

Web Dashboard refreshes AUTOMATICALLY every 30 seconds:

How it works:
  1. Browser loads dashboard
  2. JavaScript on page checks for auto-refresh flag
  3. Every 30 seconds: Silently fetches latest page
  4. Page reloads automatically
  5. User sees updated data (no action needed)

Customization:
  • Change interval in templates/base.html
  • Edit: const refreshInterval = 30000; (milliseconds)
  • 30000 = 30 seconds
  • 60000 = 60 seconds

================================================================================
THREAD SAFETY
================================================================================

Why separate threads?

Thread 1 (Background): Flask
  • Handles HTTP requests
  • Serves web dashboard
  • Can run indefinitely
  • Doesn't block UI

Thread 2 (Main): Simulator
  • Handles Tkinter GUI
  • Python requirement: Tkinter on main thread
  • User interaction
  • Responsive and immediate

No shared state = No race conditions!

CONFIGURATION
================================================================================

Default Settings:
  • Flask Port: 5000
  • Auto-refresh Interval: 30 seconds
  • Both apps: Separate threads

To Change Settings:

1. Flask Port (edit app_launcher.py):
   flask_app.run(port=8000)  # Change from 5000

2. Refresh Interval (edit templates/base.html):
   const refreshInterval = 60000;  // Change from 30000

3. Disable Auto-refresh (in browser console):
   sessionStorage.setItem('enableAutoRefresh', 'false');
